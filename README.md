# Colloquy research desk

Live site: https://vedaantk.github.io/research-desk/

These are the published results of Colloquy, an autonomous research loop for systematic S&P 500
strategies:

1. Claude turns a plain-English idea into a spec, and Codex writes the code.
2. Three independent backtest engines must reconcile on every trade.
3. Each version is critiqued, then has to clear pre-registered risk gates.
4. Survivors face a sealed holdout period, which is opened once.

Every idea is listed, including the ones that failed.

This repository contains only the static site and portfolio-level aggregates: equity curves,
yearly returns and summary statistics. A machine running the research loop regenerates it
automatically. No holdings or security-level data are published.

Backtested, hypothetical results. This is not investment advice.
